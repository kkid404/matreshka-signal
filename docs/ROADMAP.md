# Roadmap — Matryoshka Scanner

Файл для отслеживания прогресса разработки. Обновляем по ходу работы.

---

## v1.0 — MVP (базовый сканер)

- [x] **Модели данных** — `Candle`, `SignalCard`, `Direction`, `LadderStep`
- [x] **Конфиг** — все параметры стратегии через dataclass (`ScannerConfig`)
- [x] **Загрузка данных** — Bybit OHLCV через ccxt, пагинация, ретраи
- [x] **Индикаторы** — EMA, ATR, расчёт теней/тела, проверка позиции закрытия
- [x] **Уровни (ручной режим)** — `levels_manual` по символам
- [x] **Детектор сигнала** — 5 шагов: контекст D1 → касание уровня H4 → триггер → параметры → валидация
- [x] **Расчёт Entry / SL / TP** — по RR target (по умолчанию 3R)
- [x] **Вероятность %** — бэктест на истории H4, win/loss/unresolved, размер выборки
- [x] **Вывод** — rich-консоль (карточки + таблица), JSON, CSV
- [x] **Кэш сигналов** — дедупликация, файловое хранение
- [x] **Daemon-режим** — сканирование каждые 5 мин
- [x] **Юнит-тесты** — 27 тестов (индикаторы, сигналы, вероятность)
- [x] **README + requirements.txt**
- [x] **STRATEGY.md** — описание стратегии простым языком для пользователя
- [x] **Telegram-уведомления** — отправка карточек сигналов через Bot API
- [x] **.env + .gitignore** — безопасное хранение токенов

---

## v1.1 — Улучшения и стабильность

- [ ] **Конфиг из файла** — загрузка настроек из `config.yaml` / `config.json` вместо хардкода
- [ ] **Фильтр символов** — автоматический top-N по объёму + фильтр min volume / OI
- [ ] **Лесенка TP** — полноценная поддержка `ladder_steps` с частичным закрытием и переносом SL в BE
- [ ] **Логирование в файл** — ротация логов, уровни DEBUG/INFO/WARNING/ERROR
- [ ] **Расширенная валидация** — проверка на реалистичность TP, фильтр по ATR
- [ ] **Обработка edge-cases** — пустые данные, неликвидные пары, пропуски свечей
- [ ] **Интеграционный тест** — прогон на 1–2 реальных монетах, сверка с ручным анализом

---

## v1.2 — Авто-уровни (levels_auto)

- [ ] **Фрактальные swing highs/lows** — поиск экстремумов (уже есть заготовка в `levels.py`)
- [ ] **Кластеризация уровней** — объединение близких уровней в зоны (заготовка есть)
- [ ] **Выбор ближайших к цене** — автоматический отбор N ближайших уровней
- [ ] **Переключение режимов** — `levels_mode = "auto"` полностью рабочий
- [ ] **Тесты авто-уровней** — проверка на синтетических и реальных данных

## v2.0 — Оповещения и визуализация

- [x] **Telegram-бот** — отправка карточек сигналов в Telegram-канал
- [ ] **Webhook** — опциональный HTTP-вебхук для интеграции с другими системами
- [ ] **Web-дашборд** — мини-интерфейс для просмотра сигналов (FastAPI + React / Streamlit)
- [ ] **Графики** — генерация PNG/SVG графиков свечей с отмеченным сигналом
- [ ] **TradingView alerts** — автоматические ссылки / Pine Script export

---

## v2.1 — Аналитика и оптимизация

- [ ] **Статистика сигналов** — дашборд: win rate по символам, по дням недели, по времени
- [ ] **Оптимизация параметров** — grid search по `min_wick_ratio`, `close_position_k`, `rr_target`
- [ ] **Monte Carlo** — оценка ожидаемого P&L при заданном risk management
- [ ] **Мульти-таймфрейм** — поддержка H1 / H2 / H6 помимо H4
- [ ] **Корреляция с BTC** — фильтр сигналов по состоянию BTC (risk-on / risk-off)

---

## v3.0 — Продвинутый функционал

- [ ] **Мульти-биржа** — поддержка Binance, OKX через ccxt
- [ ] **Портфельный режим** — ограничение одновременных сигналов, корреляционный фильтр
- [ ] **Машинное обучение** — скоринг сигналов по дополнительным фичам (объём, OI, фандинг)
- [ ] **Бэктест-движок** — полноценный бэктест с equity curve, drawdown, Sharpe ratio
- [ ] **Paper trading** — подключение к testnet Bybit для виртуальных сделок

---

## Заметки

- Приоритет: сначала v1.1 (стабильность), затем v1.2 (авто-уровни), потом v2.0 (остальные оповещения)
- Скрипт **НЕ открывает сделки** — все решения принимает пользователь
- При добавлении фичи — сначала тест, потом реализация
