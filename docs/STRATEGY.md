# Стратегия «Матрёшка» — простым языком

## Суть в двух словах

Мы ищем моменты, когда цена **отскакивает от важного уровня** в направлении общего тренда.  
Как матрёшка: большой тренд (дневной) содержит внутри себя точку входа на меньшем таймфрейме (4-часовом).

---

## Шаг за шагом

### 1. Определяем направление — «куда дует ветер»

Смотрим на **дневной график (D1)** и считаем среднюю цену за последние 50 дней (EMA 50).

- Цена **выше** средней → тренд вверх → ищем **только покупки (LONG)**
- Цена **ниже** средней → тренд вниз → ищем **только продажи (SHORT)**

Это как компас: мы не торгуем против течения.

```
Цена ~~~~~/‾‾‾‾‾‾‾‾       ← цена выше EMA = LONG ONLY
         /
EMA ----/------------------
       /
      /____________________  ← цена ниже EMA = SHORT ONLY
```

### 2. Находим важный уровень — «стена»

На **4-часовом графике (H4)** есть ценовые уровни, от которых цена раньше разворачивалась.  
Это зоны поддержки (снизу) и сопротивления (сверху).

- Для **LONG**: ищем уровень поддержки — «пол», от которого цена отталкивается вверх
- Для **SHORT**: ищем уровень сопротивления — «потолок», от которого цена отталкивается вниз

Уровни задаются вручную (вы сами отмечаете ключевые цены для каждой монеты).

```
Сопротивление ═══════════  ← SHORT отсюда
                  ▲
                  │
Цена          ●───┘
                  │
                  ▼
Поддержка     ═══════════  ← LONG отсюда
```

### 3. Ждём свечу отказа — «сигнальная свеча»

Когда цена дошла до уровня, нужна **особая свеча** — подтверждение разворота.

Для **LONG** (покупка) свеча выглядит так:
- Длинная **нижняя тень** (хвост вниз) — цена попыталась уйти ниже, но покупатели вернули её
- Закрытие свечи в **верхней части** — покупатели победили

```
   ┌──┐
   │██│ ← закрытие наверху (тело)
   │██│
   └──┘
     │
     │   ← длинная нижняя тень = продавцы не смогли
     │
     ╵
```

Для **SHORT** (продажа) — зеркально: длинная верхняя тень, закрытие внизу.

### 4. Рассчитываем точки входа, стопа и цели

Если сигнальная свеча найдена, бот рассчитывает:

- **Entry (вход)** — цена закрытия сигнальной свечи
- **Stop-Loss (стоп)** — чуть ниже хвоста свечи (для LONG) или выше (для SHORT)
- **Take-Profit (цель)** — на расстоянии 3× от стопа

```
Пример LONG:

Take-Profit ─── +300      (3R — в три раза дальше стопа)
                  ▲
                  │ 300
                  │
Entry ────────── 100       (вход)
                  │ 100
                  ▼
Stop-Loss ────── 0         (стоп)

Риск = 100 пунктов, Цель = 300 пунктов → соотношение 1:3
```

**Зачем 1:3?** Даже если вы правы только в 30% случаев, вы всё равно в плюсе:
- 10 сделок: 3 победы × 300 = 900, 7 проигрышей × 100 = 700 → **чистая прибыль 200**

### 5. Проверяем вероятность по истории

Бот прогоняет эти же правила по **прошлым данным** (тысячи 4-часовых свечей) и считает:

- Сколько раз такой сигнал приводил к **победе** (цена дошла до TP)
- Сколько раз — к **проигрышу** (цена дошла до SL)
- Итого: **вероятность %** = победы / (победы + проигрыши)

Также показывает **размер выборки (N)** — сколько таких сигналов было в истории.  
Если N меньше 30 — бот предупреждает: «мало данных, статистика ненадёжна».

---

## Что выдаёт бот

Для каждого сигнала бот формирует **карточку**:

| Поле | Пример |
|---|---|
| Монета | BTCUSDT |
| Направление | LONG |
| Таймфрейм | H4 |
| Время сигнала | 2024-01-15 08:00 UTC |
| Уровень | 43000 |
| Вход | 43250 |
| Стоп-лосс | 42800 |
| Тейк-профит | 44600 |
| RR | 1:3 |
| Вероятность | 42% |
| Выборка (N) | 47 сигналов |
| Ссылка | TradingView |

## Другие стратегии (больше сигналов)

Теперь сканер умеет работать не только по «Матрёшке», но и по нескольким стратегиям сразу.
Это нужно, чтобы увеличить частоту сигналов и не ждать редкий идеальный сетап.

### 1) EMA Bounce (частая)

**Идея:** рынок в тренде, цена откатывает к EMA21 на H4 и снова уходит по тренду.

- Контекст берём с D1 (EMA50)
- На H4 ждём касание/прокол EMA21
- Свеча должна закрыться обратно по тренду
- TP по умолчанию: около 2R

Когда хорошо работает: в стабильных трендовых фазах.

### 2) Breakout (средняя частота)

**Идея:** цена пробивает важный уровень и подтверждает пробой объёмом.

- Контекст D1 по EMA50
- На H4 ищется пробой swing-уровня
- Объём сигнальной свечи выше среднего
- TP по умолчанию: около 2R

Когда хорошо работает: на выходе из консолидаций.

### 3) Engulfing (средняя частота)

**Идея:** свеча поглощения возле уровня в сторону тренда.

- Контекст D1 по EMA50
- На H4 ищется паттерн поглощения
- Паттерн должен быть рядом с уровнем
- TP по умолчанию: около 2R

Когда хорошо работает: после откатов к зоне поддержки/сопротивления.

### 4) Momentum Break (частая)

**Идея:** продолжение импульса после выхода цены за локальный диапазон.

- Контекст D1 по EMA50
- На H4 свеча закрывается выше/ниже диапазона последних баров
- Доп. фильтр: положение относительно EMA21
- TP по умолчанию: около 1.8R

Когда хорошо работает: в активных импульсных движениях.

### 5) EMA Cross (частая)

**Идея:** вход по свежему кроссу EMA9/EMA21 в сторону старшего тренда.

- Контекст D1 по EMA50
- На H4 фиксируем новый кросс EMA9 и EMA21
- Вход только если цена на стороне тренда
- TP по умолчанию: около 1.6R

Когда хорошо работает: в начале новой трендовой волны.

## Важно помнить

- Бот **не торгует сам** — он только находит потенциальные точки входа
- **Решение всегда за вами** — проверяйте сигнал на графике перед входом
- Ни одна стратегия не даёт 100% — **управляйте рисками** (не рискуйте больше 1–2% депозита на сделку)
- Чем больше **размер выборки (N)**, тем надёжнее статистика вероятности
- Уровни нужно **обновлять** по мере движения рынка

## Словарь терминов

| Термин | Значение |
|---|---|
| **EMA** | Экспоненциальная скользящая средняя — сглаженная средняя цена |
| **D1** | Дневной таймфрейм — одна свеча = один день |
| **H4** | 4-часовой таймфрейм — одна свеча = 4 часа |
| **LONG** | Покупка с расчётом на рост цены |
| **SHORT** | Продажа с расчётом на падение цены |
| **Entry** | Цена входа в сделку |
| **Stop-Loss (SL)** | Цена, при которой закрываем убыточную сделку |
| **Take-Profit (TP)** | Цена, при которой забираем прибыль |
| **RR (Risk-Reward)** | Соотношение риска к прибыли (1:3 = рискуем 1 чтобы заработать 3) |
| **Свеча отказа** | Свеча с длинной тенью — показывает, что цену «не пустили» дальше |
| **Уровень** | Ценовая зона, от которой цена исторически разворачивалась |
